# RAG 与记忆（Retrieval & Memory）

## 学习目标

- 设计从文档采集到检索到引用的 RAG 流水线。
- 区分会话状态、长期记忆与外部知识库。
- 理解来源时间、冲突更新与数据删除的重要性。

## 核心概念

Chunking；Embedding；Dense / Sparse / Hybrid Search；Rerank；Metadata Filter；Top-k；引用链；Precision@k；Recall@k；状态、短期记忆、长期记忆。

## 思考题

1. 这部分的哪些失败可通过确定性代码预防？
2. 如果工具或模型没有按预期工作，系统应如何观测和恢复？
3. 什么情况下不该采用更复杂的 Agent 设计？

## 实验任务

使用 30–100 篇小文档建立检索集。准备 20 道问答及期望证据，比较关键词检索与语义检索并标明引用。

## 验收标准

能识别“资料中不存在的答案”；引用必须指向真实文本；将记忆更正后不得继续使用被纠正的旧事实。
