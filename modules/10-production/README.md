# 生产部署与可靠性（Production Engineering）

## 学习目标

- 将实验 Agent 改造为可运维服务。
- 实现版本管理、持久状态、限流与监控。
- 评估用户体验、价格与可靠性之间的取舍。

## 核心概念

Docker；CI/CD；队列；重试/指数退避；Rate Limit；Circuit Breaker；Checkpoints；Tracing；SLO/SLA；成本告警；多租户与数据隔离；迁移策略。

## 思考题

1. 这部分的哪些失败可通过确定性代码预防？
2. 如果工具或模型没有按预期工作，系统应如何观测和恢复？
3. 什么情况下不该采用更复杂的 Agent 设计？

## 实验任务

将综合 Agent 部署到测试环境，使用人为注入的超时、断连、重复提交和模型失败来演练恢复；编写运行手册。

## 验收标准

提供 Demo、日志/Trace、故障演练、运行手册、指标看板方案、成本预算与安全审批流程。
