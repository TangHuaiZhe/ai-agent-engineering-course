# 工作流与编排（Orchestration）

## 学习目标

- 识别何时使用固定工作流，何时使用动态规划。
- 建模多步骤任务的状态转移与依赖关系。
- 支持并行任务、重试、人工审批和中断恢复。

## 核心概念

Sequential；Routing；Parallelization；Evaluator–Optimizer；Supervisor / Worker；Handoff；状态机；Checkpoint；Saga / Compensation；Human-in-the-Loop。

## 思考题

1. 这部分的哪些失败可通过确定性代码预防？
2. 如果工具或模型没有按预期工作，系统应如何观测和恢复？
3. 什么情况下不该采用更复杂的 Agent 设计？

## 实验任务

实现“查资料 → 提取结构化事实 → 校验 → 审批 → 生成报告”的工作流，注入随机中断，确保恢复后不会重复写入。

## 验收标准

提交工作流状态图；覆盖至少一个分支、一次失败重试、一个人为审批和一次断点恢复。
