# 软件工程基础（Software Engineering）

## 学习目标

- 以 Python 或 TypeScript 构建一个 API 服务；理解异步、超时、重试与幂等。
- 用 JSON Schema 或等价类型约束工具的输入输出。
- 建立可运行的单元测试、日志与配置加载。

## 核心概念

HTTP 请求生命周期；异步任务与并发；错误分类；API 鉴权；持久化与队列；依赖注入；测试金字塔。

## 思考题

1. 这部分的哪些失败可通过确定性代码预防？
2. 如果工具或模型没有按预期工作，系统应如何观测和恢复？
3. 什么情况下不该采用更复杂的 Agent 设计？

## 实验任务

编写一个 `ToolExecutor`：只有白名单注册过的函数可执行。输入必须经过类型验证；对重复的请求 ID 返回同一执行结果；超时或异常时返回结构化错误。

## 验收标准

提供 5 个成功用例及至少 3 个失败用例（非法参数、未知工具、重复执行）。不要用宽泛的 `except` 吞掉异常。
