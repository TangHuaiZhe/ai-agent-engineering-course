# 大语言模型基础（LLM Foundations）

## 学习目标

- 理解模型生成的概率性与 Token 预算。
- 掌握基础 Prompt 模板、结构化输出与模型选择。
- 能区分“模型产生文本”和“程序执行工具”这两种行为。

## 核心概念

Transformer / Attention 的直觉；Tokenization；Context Window；Temperature；Function Calling；Structured Outputs；Prompt 与指令层级；模型能力、成本、延迟取舍。

## 思考题

1. 这部分的哪些失败可通过确定性代码预防？
2. 如果工具或模型没有按预期工作，系统应如何观测和恢复？
3. 什么情况下不该采用更复杂的 Agent 设计？

## 实验任务

为同一组 20 道任务分别设计自由文本输出与结构化输出方案，记录解析失败、事实错误、成本与延迟，不要凭主观印象判断。

## 验收标准

输出可复现的实验记录，注明模型标识和实验日期。描述哪些错误能由 Schema 消除，哪些仍必须核验语义。
