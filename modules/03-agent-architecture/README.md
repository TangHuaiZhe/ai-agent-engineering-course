# Agent 架构与循环（Agent Architecture）

## 学习目标

- 理解观察—行动循环、工具选择与停止条件。
- 区分 Agent、Workflow、RAG 与普通聊天应用。
- 从零实现支持迭代、错误返回、步数限制的最小 Agent。

## 核心概念

Agent Loop；ReAct；Planning；Reflection；任务分解；状态；多工具决策；部分失败；终止规则；预算约束；单 Agent vs 多 Agent。

## 思考题

1. 这部分的哪些失败可通过确定性代码预防？
2. 如果工具或模型没有按预期工作，系统应如何观测和恢复？
3. 什么情况下不该采用更复杂的 Agent 设计？

## 实验任务

先运行 `examples/deterministic_loop.py`。实现模型适配器接口，允许切换模拟决策与真实模型决策。加入最大 5 次工具调用限制。

## 验收标准

必须证明循环在成功、工具失败、重复调用、达到步数预算时都能正确终止；不能有无限循环或凭空宣称工具已执行。
