# 工具调用与 MCP（Tools & MCP）

## 学习目标

- 理解 Tool Contract、类型校验与认证授权。
- 理解 MCP 的 Tools、Resources、Prompts 及其信任边界。
- 设计只读与有副作用的工具的不同执行策略。

## 核心概念

Function Calling；JSON Schema；Tool Registry；MCP Client / Server；OAuth；参数校验；副作用；幂等键；执行沙箱；技能/Skills 与协议的区别。

## 思考题

1. 这部分的哪些失败可通过确定性代码预防？
2. 如果工具或模型没有按预期工作，系统应如何观测和恢复？
3. 什么情况下不该采用更复杂的 Agent 设计？

## 实验任务

开发一个只读的任务清单查询工具与一个需要人工审批的更新工具；以 MCP Server 暴露并用独立 Client 调用（依当前官方 SDK 文档）。

## 验收标准

验证越权参数被拒绝、修改操作需要授权、工具输出不能注入系统指令；记录请求和响应的类型。
