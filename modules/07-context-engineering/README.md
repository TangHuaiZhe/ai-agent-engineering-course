# 上下文工程（Context Engineering）

## 学习目标

- 理解模型上下文是受限资源，而不是无限日志。
- 将指令、证据、对话状态和工具结果分层。
- 能定量比较上下文裁剪和压缩对质量的影响。

## 核心概念

System Instructions；动态 Context；Token Budget；Prompt Caching；摘要压缩；检索选择；事实 vs 指令；长任务防漂移；Provenance。

## 思考题

1. 这部分的哪些失败可通过确定性代码预防？
2. 如果工具或模型没有按预期工作，系统应如何观测和恢复？
3. 什么情况下不该采用更复杂的 Agent 设计？

## 实验任务

对 30 轮模拟任务分别使用“完整历史”“最近 N 轮”“事实摘要+按需检索”，测量 Token、成功率和细节遗漏。

## 验收标准

压缩后不可删除关键约束与未完成的待办事项；恶意工具输出不能提升到高优先级指令层。
