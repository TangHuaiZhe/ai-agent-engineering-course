# Labs：实践任务索引

| 实验 | 所属模块 | 难度 | 交付物 |
|---|---|---|---|
| Lab 01 最小工具执行器 | 01–03 | 初级 | 有终止条件的 Agent Loop；单元测试 |
| Lab 02 MCP 与授权 | 04 | 中级 | Server/Client、权限表、越权测试 |
| Lab 03 RAG 证据检索 | 05 | 中级 | 数据集、检索实现、引用评测 |
| Lab 04 可恢复工作流 | 06–07 | 中级 | 状态机、持久检查点、上下文预算 |
| Lab 05 Eval / Security | 08–09 | 高级 | 测试集、Trace、威胁模型、回归报告 |
| Lab 06 生产级综合项目 | 10 | 高级 | 可运行项目、运行手册、验收报告 |

每个实验至少包括：目标、架构、运行步骤、成功用例、失败用例、度量指标以及复盘。详细任务描述见各[模块](../README.md#课程地图)的「实验任务」和综合项目说明。
