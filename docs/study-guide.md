# 如何学这门课

每周按 **概念 → 最小实验 → 失败注入 → 测量 → 复盘** 五步推进。

- **概念**：写出关键机制、边界以及不适用的场景。
- **最小实验**：控制变量，不急于引入第三方 Agent 框架。
- **失败注入**：故意让工具超时、返回错误、输出污染内容。
- **测量**：记录成功率、调用步数、耗时以及成本（如果使用付费模型）。
- **复盘**：把最小可重现失败用例纳入测试集。

## Definition of Done（完成定义）

一个练习只有在具备运行步骤、至少一个成功测试、一个失败测试和简要复盘时才算完成。

## 建议的笔记规范

每篇笔记包括：一句话定义、一个反例、一个时序图（如适用）、三条常见错误、一个真实的工程取舍。

## 防止“框架驱动学习”

先学习概念与协议，再选择具体 SDK；工具与模型可能随版本改变，但数据流、状态机、权限边界和评测思想相对稳定。
