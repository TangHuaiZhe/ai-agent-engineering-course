# 先修知识

最重要的基础并非深度学习数学，而是对软件工程中**状态、接口和故障**的理解。

## 必备

- 了解 Python 或 TypeScript 的函数、类、异常和类型标注。
- 理解 HTTP、JSON、REST API、鉴权、同步与异步。
- 能使用 Git、命令行，编写基本单元测试。
- 知道数据库、缓存与队列分别负责什么。

## 先了解即可

- Transformer、Attention 的直觉；Token 与概率采样的意义。
- 向量和余弦相似度，不需先推导复杂梯度公式。
- Docker 与持续集成的基本用途。

## 本课程实践环境

- Python 3.11+，Git，文本编辑器或 IDE。
- 建议使用虚拟环境；基础示例不需任何第三方依赖。
- 真实模型示例需要自行提供 API Key；请始终以环境变量管理凭证。
- 数据库、MCP 与部署在对应课程阶段增量添加，不要求第一周全部安装。
