# 综合项目验收标准

## 功能与证据

- [ ] 给定一个标的和截止日期，可以完成任务并生成报告。
- [ ] 报告的所有关键数字具备来源、日期、期间、单位与计算公式。
- [ ] 来源缺失或冲突时明示，不虚构数据。
- [ ] 对同一任务重复运行可追溯差异。

## 可靠性

- [ ] 工具超时有界重试；重复任务不产生重复写入。
- [ ] 系统有最大步数、最大执行时间与成本预算。
- [ ] 中断恢复后保持一致性。

## 安全与权限

- [ ] 外部网页中的指令不会被当作系统权限。
- [ ] 无权执行交易、修改授权范围或读取未经批准的秘密。
- [ ] 有副作用的操作需明确授权与审计。

## 评测与可观测性

- [ ] 有固定测试集，覆盖正常、缺失、冲突、错误和恶意输入。
- [ ] 有 Trace，能定位失败所在节点及工具调用。
- [ ] 记录任务成功率、引用准确率、延迟、调用数与成本。

## 人工审核清单

- 公司身份是否消歧？
- 财报口径、币种、单位和时间段是否一致？
- 是否区分事实/推断/观点？
- 负面证据与反例是否保留？
- 是否明确列出无法验证的信息？
