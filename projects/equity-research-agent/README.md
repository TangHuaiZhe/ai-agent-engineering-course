# Capstone：上市公司研究 Agent

## 项目目标

在输入证券标识、研究问题和时间范围后，Agent 收集可追溯的公开材料，提取公司与行业事实，运行确定性计算，并形成带有来源的研究报告；结果由核验流程检查，不应将模型推断冒充客观数据。

## 目标用户故事

- 作为研究者，我希望查看某家公司最近一个财年收入、盈利和现金流的公开数据及**原始引用**。
- 作为研究者，我希望知道哪些数据是事实，哪些是模型的分析假设。
- 作为研究者，我希望在证据不足或数据冲突时得到明确提示，而不是一个编造出来的答案。
- 作为审核者，我希望能看到检索、抽取、计算和最终写作各阶段的 Trace。

## MVP 范围

1. 公司标识解析与财报/公告数据采集（仅来自授权或公开接口）。
2. 将原始文件与 URL、发布时间、抓取时间、文档版本关联。
3. 提取结构化指标，明确币种、单位、期间及会计口径。
4. 用确定性代码计算变化率、利润率、估值等数值；输入缺失时拒绝计算。
5. 出具研究结论，明确数据出处、分析假设、不确定性与反例。
6. 核验报告中的数字、日期、引用对应关系，并记录失败。

## 不做什么

- 不模拟或伪造市场数据，不输出无法复现的假精确收益预测。
- 不让模型直接发起有副作用的交易；研究系统为只读优先。
- MVP 不做复杂 Multi-Agent；只有单 Agent + 确定性流程无法满足要求时才拆分。
